### 环境注意事项（补充）
- PowerShell 的 stdout 全部丢失（返回 exit 0 但无输出）。**所有命令必须把结果 `Set-Content -Encoding UTF8 <file>` 再用 Read 读回**；且需先 `$ErrorActionPreference='SilentlyContinue'`，否则原生命令的 stderr 会中断脚本导致文件根本没写。
- 不能用 `2>&1 | Out-String` 再 `Add-Content`，会产出 UTF‑16 二进制；统一 `Set-Content -Encoding UTF8`。
- HTML→DOCX 走 `html-to-docx` skill（tencent-docx 插件）。官方托管 venv `~/.venv-html-to-docx` **从未安装**，且 setup 脚本依赖 bash + uv（本机 bash 已坏）。可行替代：用 **Python 3.11** 建 venv `C:\Users\ROG\.workbuddy\binaries\python\envs\htd311`，`pip install -r skills/html-to-docx/scripts/requirements.txt`（Python 3.13 装不上，Pillow<11 无 cp313 wheel），再 `set PYTHONPATH=<...>\skills\html-to-docx\scripts` + `python -m html_to_docx convert in.html -o out.docx --margin-left 2.6 --margin-right 2.6`。已验证可用。
- html-to-docx 的坑：空 `<td></td>` 会被当成「待填写字段」生成书签，需先替换为全角空格 `\u3000`；`<br>` 会拆段；表格单元格 background-color 支持不完整，表格设计不要依赖底色表达含义。
- 版式可用：`<section role="cover">` + `@page cover` 做「封面无页眉页脚、正文有」，页脚 `content: counter(page) " / " counter(pages)` 会转成 Word 域。
