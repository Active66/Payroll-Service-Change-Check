### 环境注意事项（补充）

- HTML→DOCX 走 `html-to-docx` skill（tencent-docx 插件）。官方托管 venv `~/.venv-html-to-docx` **从未安装**，且 setup 脚本依赖 bash + uv（本机 bash 已坏）。可行替代：用 **Python 3.11** 建 venv `C:\Users\ROG\.workbuddy\binaries\python\envs\htd311`，`pip install -r skills/html-to-docx/scripts/requirements.txt`（Python 3.13 装不上，Pillow<11 无 cp313 wheel），再 `set PYTHONPATH=<...>\skills\html-to-docx\scripts` + `python -m html_to_docx convert in.html -o out.docx --margin-left 2.6 --margin-right 2.6`。已验证可用。

### md→docx 的批量转换做法（比手写 HTML 快，可复用）
- 自己写 `md2html.py`：解析标题/表格/列表/代码块，套用**已验证 100 分的那份 CSS**（直接从旧 html 里正则抽 `<style>` 复用），封面与目录由脚本拼接。
- 细节：行内 `**粗体**`→`<strong>`、`` `code` ``→`<span class="mono">`（只设 font-family，不设 background/padding，避开 SI-07 badge 检测）；代码块用单列 `<table class="code">` + `<thead>` 表头。
- 每章 h2 后必须有一句导语，否则 TQ-03 报错；用 `patch_md.py` 批量插入，比逐处手改可靠。
- 引号：把正文 ASCII `"` 成对换成中文引号可读性更好，但 **html-to-docx 会在引号两侧插空格**（`这类的 “ 偶发一次 ”`），这是转换器行为，HTML 里没有空格，改不掉，接受即可。
- 同理，中文与数字之间的单个空格在 docx 里会变成双空格（`出现  1  例`），不影响理解。
